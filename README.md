# CI/CD Pipeline That Blocks Bad Merges

## About This Project

This project is created to learn and demonstrate a basic CI/CD process using GitHub, GitHub Actions, ESLint, and Jest.

The main idea is to check the code automatically before it is merged into the main branch.

If the code has errors or the test fails, the Pull Request should not be merged.

## Technologies Used

- Node.js

- Git
- GitHub
- ESLint
- Jest
- GitHub Actions
